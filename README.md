### 3. Experiential Learning Capstone: HWGuard Universal Hardware Vault

**HWGuard** (`25BTARD079_Experiential_Learning/FINALPROJECT.py`) is a cryptographic hardware integrity tool engineered to run portably (e.g., from a secure USB pendrive) to protect systems against physical component theft, unauthorized memory swapping, motherboard tampering, and covert hardware alterations.

#### 🔐 Security & Architectural Highlights
* **Zero Raw Serial Storage:** Raw serial numbers and vendor IDs are never stored. Components are hashed using cryptographic algorithms with distinct per-device salt values.
* **Scrypt Key Derivation:** Strong key derivation (`n=2^15, r=8, p=1`, `dklen=32`) makes brute-force and dictionary attacks computationally infeasible.
* **HMAC-SHA256 Password Verification:** Validates configuration update authorization without ever storing plaintext passwords.
* **Append-Only Tamper-Evident Hash Chain:** System state transitions are logged as an append-only ledger in `./hwguard_data/state.json`, producing a cryptographic head hash suitable for verification.
* **Cross-Platform Compatibility:**
  * 🪟 **Windows:** `HWGuard.bat` (native SMBIOS, disk & RAM verification)
  * 🍎 **macOS:** `HWGuard.command` (Logic Board, memory & storage auditor)
  * 🐧 **Linux:** `HWGuard.sh` (sysfs hardware auditor)
  * 📱 **Android / Web:** `HWGuard.html` (offline portable dashboard for mobile/OTG)

## 🚀 Getting Started

### Prerequisites
* **Python 3.10+** installed on your system.
* **Git** installed on your system.

Verify your installation:
```bash
python --version
git --version
```

### Installation & Repository Clone
```bash
# Clone the repository
git clone https://github.com/viradiyaprachi7978-maker/25BTRAD079_Python.git

# Navigate into the project root
cd 25BTRAD079_Python
```

### Executing Any Program

#### Run Lab Experiments
```bash
# Run arithmetic and geometry calculator (Lab 4)
python 25BRAD079_Lab_Experiments/Lab_Experiment_1/4.py

# Run guessing game, prime checker & Fibonacci (Labs 5-7)
python 25BRAD079_Lab_Experiments/Lab_Exercise_02.py

# Run contact manager & word frequency (Labs 8-10)
python 25BRAD079_Lab_Experiments/Lab_excercise_03.py

# Run log analyzer & employee payroll (Labs 11-13)
python 25BRAD079_Lab_Experiments/Lab_Exercise_04.py

# Run OOP Bank Account & Library Management (Labs 14-16)
python 25BRAD079_Lab_Experiments/Lab_Excercise_05.py
```

#### Run Problem-Solving Utilities
```bash
# Run the Attendance Tracker
python 25BRAD079_Problem_Solving/Attendance_Tracker.py

python 25BRAD079_Problem_Solving/Student_Grading_Automation.py
```
